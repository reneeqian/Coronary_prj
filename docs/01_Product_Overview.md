# Product Overview – Coronary_prj

## 1. Project Purpose

Coronary_prj is a demonstrative software project designed to showcase
robust engineering practices in medical imaging AI development.

This project is intended as:

- A portfolio demonstration
- A learning exercise in SaMD-grade software design
- An example of IEC 62304-aligned software lifecycle thinking
- A demonstration of traceability, risk analysis, and verification rigor

This project is NOT intended for clinical use.

---

## 2. Intended Context (Educational Only)

The software simulates analysis of gated chest CT images to detect and
quantify coronary artery calcium (CAC).

The system architecture mirrors what a clinical SaMD product might include,
but it is provided for educational and engineering demonstration purposes only.

---

## 3. Explicit Non-Clinical Disclaimer

This software:

- Is not validated for clinical use
- Has not undergone regulatory review
- Must not be used for diagnosis or patient care
- Is not a medical device

It is a demonstration of disciplined medical software engineering practices.

---

## 4. Demonstrated Engineering Concepts

This project demonstrates:

- Structured requirement definition
- Traceability from requirement → test
- Deterministic data ingestion
- Risk identification and mitigation documentation
- Verification and validation planning
- Modular architecture design
- Clean separation of concerns

---

## 5. Target Audience

- Hiring managers in medical device companies
- Regulatory professionals
- Software engineering interviewers
- AI/ML teams in regulated environments
